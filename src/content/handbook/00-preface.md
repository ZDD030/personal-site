## 写在开始

有幸拜读[《上海交通大学生存手册》](https://survivesjtu.gitbook.io/survivesjtumanual)后，我看到了同龄人在面对教育现状时的思考，以及他们为自己寻找出路的尝试。

[《上海交通大学生存手册》](https://survivesjtu.gitbook.io/survivesjtumanual)是上交学子编写的、面向上交新生的指南，其中许多内容都很有启发性。我也是在认真阅读之后，萌生了写作这份手册的想法。

写一份开源的且面向全体新生的指南，缩小同学之间的信息差，帮助大家更好地在大学里学习、生活并提升自我，这便是这份手册的写作初衷。

这也让我更想写一份属于**普通四非院校的生存指南**，尤其是身处偏远地区的特殊学校的同学，留下一些贴近实际的经验。

喀什大学的地理位置与校园环境，让这里的大学生活有着自身的特点。与此同时，喀大学子也面临着许多与其他双非、四非院校学生相通的问题。这些具体处境，是我写这份手册的出发点。

回望大学三年，机遇与变化始终交织，每一年都有新的选择与变数。如何兼顾学业与个人追求，如何在学校的各项规章制度下安排自己的生活并争取想要的机会，是我反复思考的问题，也是许多喀大学子需要面对的难题。

我愿称这种处境为“**带着镣铐跳舞**”：感受到现实的约束，也仍想在其中争取一些空间，走出自己的路。

大学生活里，有些事情能在通知与文件中找到答案，有些则需要自己摸索：怎样安排学习，怎样寻找信息，怎样选择一条适合自己的路。

我想在这份手册里，把这些问题和自己的经验逐步整理出来。第一篇先回望我与喀大的三年：从最初难以接受录取结果，到参加竞赛、去广工联培，再到接触科研和准备升学。写下这些经历，也是在交代后面那些经验和判断是怎样形成的。其他篇章会结合具体问题，写专业学习与升学，也留一些篇幅给日常生活、人与人的相处，以及对自己的认识。

> 他山之石，可以攻玉。

经验的价值，在于让后来者多一种参考。每个人的条件、目标和处境都不相同，希望你能带着自己的问题阅读，也保留自己的判断。

## 写给谁

写给初来喀大、尚不熟悉大学生活的同学，也写给已经走过一段路、正在重新考虑学习与未来方向的人。这份手册，也写给曾经迷茫、焦虑的自己。

## 怎样阅读

各篇可以独立阅读，按自己关心的问题选择即可。如果想先了解我的求学经历，可以读[《喀大于我，我与喀大》](/handbook/kashgar-and-me/)；想了解课程、专业或升学方面的经验，可以在[手册目录](/handbook/)中选择相关篇章。

目录中的编号方便查找和组织篇章，阅读时不必从头开始。后续写作也会按实际经历和问题展开，篇章的主题与安排会随内容逐步调整。

## 关于更新

手册正在逐步编写。序与第一篇已有初稿，第一篇关于录取和大学三年的回顾已经写下，其他小节还在补充；其余篇章目前以提纲为主。这些提纲是暂定的写作方向，后续会根据实际内容调整。具体经历、资料链接和适用年份会继续补充，涉及学校规定的内容将注明出处与时间。

## 关于贡献

本书是一份喀什大学生存指南，由我更新与维护。部分内容可能偏向电气等工科专业，欢迎有兴趣的同学进一步补充与拓展。

大部分同学并非 CS（Computer Science，计算机科学）专业出身，我也是依靠前期做项目积累的经验，用 VS Code 编辑文档、用 Markdown 写作、用 Git 和 GitHub 协作并更新网页内容，再借助 AI 辅助编辑，才逐步完善了这份手册，目前仍处于边学边做的状态。

这些操作对初次接触的同学而言可能较为复杂，我的技术知识与讲解能力也有限。要求非 CS 专业的贡献者学习并掌握这些技能，需要投入时间和精力，也会增加投稿的复杂程度与时间成本。

因此，本书只是结合喀大的实际情况，对前辈们的生存手册做一些简单的迁移，暂时不考虑通过 Fork 项目、提交 PR（合并请求）等方式开展多人协作。以目前的条件，搭建一个大而全的生存指南网站并不现实。

尽管个人视角的局限可能使内容带有偏见，我仍希望这份手册能为在喀什大学生活的彼此带来一些帮助。一方面，书中会写一些务实的内容，诸如学习节奏、机会的选择，以及保研的路径；另一方面，也保留了对[《上海交通大学生存手册》](https://survivesjtu.gitbook.io/survivesjtumanual)的部分拙劣模仿，以及对同为 L 站佬友撰写的[《致新生的你》](https://axi404.top/blog/advise)的部分引用，并尝试就大学里的心态与处事之道，给出自己的见解。

愿所愿皆所得，祝好！
