## 先读懂培养方案

刚上大学时，建议找来自己专业的培养方案，认真读一遍。未来几年要上哪些课，毕业需要修满多少学分，哪些课要先学、哪些课可以自己选，里面都有说明。提前了解这些，选课和安排学习时就能少一些盲目。

读培养方案时，可以留意这几件事：

- **毕业要求：** 必修课、选修课分别要修多少学分，实验、实习等实践环节有哪些要求，别等到临近毕业才发现漏修了课程。
- **专业主干课：** 看看专业主要学什么，哪些课程是后续学习的基础，平时要多花些功夫。
- **课程之间的联系：** 了解后面的课会用到哪些知识，前面没学懂的地方要及时补上。

学分高的课通常课时较多，对加权成绩的影响也较大，值得重视。不过，课程是否重要，还要看它在专业学习中的作用。有些实验课学分不高，却能让人发现，课本上的知识到了实际操作时，自己未必会用。

以电气类课程为例，高等数学、线性代数中的知识，在电路分析和后续专业课中会反复用到；学电机、电力系统相关课程时，又离不开电路、电磁场等基础。具体开哪些课、先学哪一门，还是要看自己所在年级和专业的培养方案。

不同学校即使开设同一个专业，课程安排也可能有所侧重。有兴趣的话，可以找其他学校的培养方案对照着看，了解它们开设了哪些方向和选修课。再结合自己的兴趣和升学打算，考虑是否需要补学一些内容。

## 上课、作业与考试

### 课堂上听不懂，可以找网课补一补

大学里，老师的授课水平不一，对教学的态度也有差别。有的老师讲得清楚，也愿意解答疑问；有的老师只是照着课件念，听完还是不明白。遇到这样的课，可以自己多读教材，找一门合适的网课，把没听懂的地方补上。

我比较推荐哔哩哔哩和中国大学 MOOC。高等数学、线性代数等基础课，可以跟着考研老师学；电气专业课可以参考水木珞研等考研机构的课程，以及纪真、郝亮亮等老师的讲解。先找自己不懂的章节听一听，觉得讲得明白、能够跟上，再继续学。

| 学习资源 | 学习建议 |
| --- | --- |
| 中国大学 MOOC | 选一门与本校课程内容相近的课，跟着学习，再做配套练习。 |
| 哔哩哔哩课程视频 | 某个知识点听不懂时，可以换一位老师的讲解试试。 |
| 考研辅导课程 | 可以用来复习基础知识和练习常见题型，但要留意与本校课程的差别。 |

**看网课时，也要对照本校的课程要求。** 其他老师讲的内容，不一定包括本校要求掌握的全部知识，作业和实验也要按时完成。网课不必同时看很多门，找到适合自己的老师后，先踏实学下去，别总在挑课程上花时间。

### 听懂以后，还要自己做题

俗话说，师傅领进门，修行在个人。老师讲得再好，自己也得下功夫。不同课程的学法不一样，但做题、推导和实验都不能省。看老师把一道例题讲完，觉得每一步都懂了，自己重新做一遍，却可能连第一步都写不出来。

学完一章，可以试着这样复习：

1. **试着把概念讲清楚。** 不照着书念，用自己的话说说它是什么意思，公式在什么条件下能用。
2. **选几道典型题自己做。** 先不看答案，从头到尾写一遍，看看能不能独立完成。
3. **弄清楚自己为什么不会。** 是概念没懂、公式用错，还是计算不熟？找出原因后，再回去看书或听课。
4. **过几天再做一次。** 尤其是看过答案才会的题，隔几天重新做，看看还记不记得解题方法。

课堂时间有限，老师不可能把教材里的每个细节都讲到。自己看书时，也要分清主次：基本概念、重要推导和常用方法应当认真掌握，其他内容可以结合教学大纲和后续学习的需要再作安排。

:::div{class="handbook-highlight"}

**复习时，别只背老师划出的题目。** 把相关知识学懂，弄清楚解题的理由；题目换个问法、条件稍有变化，也要知道该怎么做。

:::

## 成绩与排名

### 弄清成绩怎么算

每门课的成绩怎么算，老师通常会在开课时说明。平时作业、实验或实训报告、阶段测验和期末考试各占多少，最好一开始就记清楚。作业和报告按时交，实验、实训认真做，别因为漏交或拖延丢了本来能拿到的分数。

绩点和排名也要弄清楚：哪些课计入排名，是否按学分加权，补考或重修的成绩怎么处理。奖学金、推免的评定办法，要看学校当年的文件。别人的经验可以参考，但不能直接当作自己这一届的规定。

平时学得扎实，考试通常也会更有把握。不过，题目难度和临场发挥也会影响成绩。考得不理想时，可以看看试卷，回想自己是哪些地方没学懂、哪些题练得不够，还是答题时算错了、时间没安排好。知道问题出在哪里，下次才有办法改。

### 平时就要学懂，别等考前再背

我发现，身边有些同学上了大学，反而很难静下心来学习。遇到不懂的知识，等着老师给答案；到了考试前，再按划出的重点背一遍。老师怎么讲就怎么记，很少想一想为什么。大学里少了高中时的督促，如果自己也不主动学，疑问就会越积越多。

听到一个结论后，不妨多问一句：这个公式为什么能用在这里？换个条件还成立吗？这一章和前面学过的内容有什么关系？这些问题平时就要想明白。否则，考前只能靠背题应付，考完很快就忘了，后面的课用到时还得重新学。

## 英语与长期能力

英语方面，我的办法是**以赛促学、以考促学**。积极报名英语竞赛和四六级考试，督促自己坚持学习。大学里课程多，事情也多，英语很容易被搁下。有了明确的考试日期，就得提前安排准备，不能一直拖下去。

报名之后，再根据考试或比赛的要求，安排听力、阅读、写作和口语练习。忙的时候可以少学一点，但尽量不要长时间中断，更不要等到考前才开始准备。

考完之后，也可以看看自己哪一项比较弱。听力没听懂，就找一段短材料反复听，再对照原文；阅读读不明白，就试着概括每段的意思，弄清前后句的关系；写作不知道怎么表达，就积累一些常用句式，并试着用它们写自己的句子。

学专业课、做科研时，也会用到英语。查资料、读英文教材或论文，可以先试着读原文，遇到不熟悉的专业词汇，再结合上下文查一查、记下来。多读几次，相同的词汇和表达就会逐渐熟悉。

## 怎样记笔记

### 笔记里该记什么

电子笔记保存和查找都比较方便。推公式、做计算、画图较多时，可以用平板配手写笔；整理文字、课程资料和链接时，用电脑更顺手。OneNote 等工具设置好同步后，电脑、平板和手机上都能查看笔记。

习惯纸笔的话，继续用纸笔也很好。要不要买设备、用什么软件，看自己的需要和习惯就行。笔记再漂亮，资料存得再多，该理解的内容还是得自己学懂。

记笔记时，建议多记这些内容：

- **重要概念和公式：** 尽量用自己的话解释，记清公式在什么条件下适用。
- **推导和解题过程：** 记下关键步骤，也写明为什么要这样做。
- **错题和没弄懂的地方：** 写清错在哪里、正确做法是什么，暂时没解决的问题单独列出来。
- **与其他章节的联系：** 记下这一章用到了哪些旧知识，方便以后一起复习。

::summary[笔记工具怎样选择（点击展开）]

:::div{class="px-5"}

- **OneNote：** 可以把文字、手写推导和课堂资料放在一起，按课程分区整理。
- **Obsidian：** 用 Markdown 记笔记，相关的笔记之间可以添加链接，方便查阅。
- **飞书、印象笔记：** 可以整理文档和资料，也可以记录学习安排，选自己用着顺手的就好。
- **Typora：** 适合在本地写 Markdown 文档；如果需要在多台设备上使用，要另外设置文件同步。

Markdown 需要学一点语法，不过会用标题、列表、表格和引用，平时记笔记就基本够用了。其他功能等用到时再学，不必一开始就花很多时间研究软件。

:::

### 整理笔记，方便以后复习

每门课可以做一页目录，列出各章的主要内容、笔记放在哪里，还有哪些问题没弄懂。复习时先看目录，就知道该从哪里开始，也省得翻来翻去找资料。

学完一章后，可以把笔记再看一遍，补上遗漏的内容，改正当时记错的地方，再挑一两道典型题重做。隔一段时间回来复习时，能看懂自己当时为什么这样写，笔记才算有用。

:::div{class="handbook-highlight"}

**笔记是为了帮助理解和复习。记完之后能讲清楚、能自己做题，比抄得整齐、记得很多更有用。**

:::
