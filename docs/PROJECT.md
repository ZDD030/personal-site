# 个人网站项目

更新日期：2026-10-01。

用户要求复用开源 UI，提供 Firefly 与 Fuwari 为参考，并要求源码纳入 Git，方便后续上传 GitHub。当前采用 Firefly，正式源码已迁入根目录。

## 网站用途

个人介绍、项目展示、科研与技术文章，以及日常短分享。复用主题的排版、搜索、明暗模式与手机布局。

| 页面 | 当前主题路径 |
| --- | --- |
| 首页及文章列表 | `/` |
| 文章归档 | `/archive/` |
| 随记 | `/dynamic/` |
| 项目 | `/projects/` |
| 关于 | `/about/` |

站名、头像、简介、联系方式及真实内容待提供。当前主题演示资料不作为站主内容上线。

用户希望登录网页后编辑、预览、发布、撤回文章。这个需求继续保留，但主题没有自带写作后台，后续优先接入开源编辑方案。存储方式与发布流程需随编辑方案确定；原 Next.js / SQLite 规划不作为当前已完成实现。

## 当前状态

主题代码、配置、文章示例、资源、许可证与 lockfile 已上传至 [ZDD030/personal-site](https://github.com/ZDD030/personal-site) 的 `main`。`origin` 指向本站仓库，`upstream` 读取主题作者更新。网站尚未上线，下一轮具体搭建见 BUILD-NEXT.md。

原 Next.js 骨架保存在 `nextjs-initial` 标签，旧文档副本位于 `docs/history/nextjs-initial/`。`.local-archive/` 是被忽略的本机旧运行文件。

个人站与保研工作台独立，未来可同机通过主域名和子域名分流；个人站不读取保研站数据。
