## 网站用途

用于个人介绍、项目展示、科研与技术文章，以及日常短分享。重视排版和留白，参考 Astro Chiri 的简洁风格，首页和项目页单独设计。先完成文字内容，图片上传后续添加。

| 页面 | 内容 |
| --- | --- |
| `/` | 个人简介、精选项目、近期文章与随记 |
| `/articles` | 科研笔记、技术记录、保研经验；分类和标签 |
| `/notes` | 短分享、推荐链接、近期记录 |
| `/projects` | 作品介绍、演示地址、源码链接 |
| `/about` | 个人介绍、联系方式、站点信息 |
| `/admin` | 单站主登录、编辑、草稿预览、发布、撤回、导出 |

文章和随记将通过网页后台发布，内容保存到 SQLite；日常发文无需提交 Git 或重新部署。项目和关于页先用配置文件维护。公开正文支持 Markdown、表格、代码块和数学公式；不执行正文中的 HTML 或 MDX 代码。

首版不开放访客注册、评论和收费功能。姓名、头像、研究方向、联系方式、实际文章和项目链接由站主确认，初始化期间不编造个人资料。
