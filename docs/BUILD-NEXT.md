# 下一步：填充内容与准备上线

个人化框架已建立，沿用 Firefly 的界面与组件。网站名为「Thach Soul · 电气札记」，首页主标题为「往者不可谏，来者犹可追。」；个人简介已加入电气工程及其自动化、四非保研至华南理工大学（985）。

喀什大学生存手册已有序、六个主题篇章与后记；保研复盘已有提纲。填写入口和文件说明见 [内容填写指南](CONTENT-WRITING.md)。原主题示例保存在 `docs/theme-examples/`。

## 需要准备的资料

| 资料 | 用途 |
| --- | --- |
| 网站名称、公开昵称 | 标题、导航、作者署名 |
| 头像 | 个人卡片与关于页 |
| 一至三句简介 | 首页与个人卡片 |
| 愿意公开的 GitHub、邮箱等链接 | 联系方式；未提供的入口不显示 |
| 研究或学习方向、经历 | 关于页；仅发布用户确认的内容 |
| 项目简介及源码链接 | 项目展示，可先整理保研工作台 |

正式域名可后续填写，不影响本地搭建。

## 接下来具体修改

1. 修改手册序，按自己的写作口吻补充第一篇「初来喀大」，注明政策与费用的适用年份和来源。
2. 填写保研复盘的实际时间线、准备过程、申请经历与选择华南理工的判断。
3. 替换 TS 字母头像和现有横幅图片，补充愿意公开的具体学习方向。
4. 从电气笔记、技术实践、生活随想草稿模板中选择一个开始写，完成后改为 `draft: false`。
5. 确定正式域名后修改 `siteConfig.site_url`，再完成生产构建和部署。

第一轮验收时，所有公开资料属于站主，五个常用页面可正常访问，示例作者和演示文章不会混入真实内容，搜索能够找到已发布文章。

## 后续两轮

第二轮接入开源网页写作工具，完成登录、草稿、预览、发布、撤回，并确定内容更新与构建方式。此功能尚未实现，不能把 Firefly 的静态内容文件当作现成写作后台。

第三轮确定域名、服务器和备案，部署 HTTPS、版本更新与备份。个人站和保研工作台独立上线，通过不同域名入口访问。
