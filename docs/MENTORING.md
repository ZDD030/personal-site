# 电气保研辅导页面维护

更新：2026-10-08。面向 2027 年申请、通常 2028 年入学的电气学生。

公开服务说明保存在 [mentoring.md](../src/content/spec/mentoring.md)，页面排版与摘要保存在 [mentoring.astro](../src/pages/mentoring.astro)，路由为 `/mentoring/`。导航和关于页均有入口，页面复用 Firefly 的 MainGridLayout、Markdown、明暗模式与移动端布局。

## 修改入口

- 正文、套餐、价格、服务期限、沟通约定与咨询邮箱：修改 `src/content/spec/mentoring.md`。
- 页面标题、搜索摘要和表格样式：修改 `src/pages/mentoring.astro`。
- 顶部导航入口：修改 `src/config/navBarConfig.ts`。
- 关于页入口：修改 `src/content/spec/about.md`。

## 当前公开细则

基础指导、半包辅导、全包辅导分别为 200、300、500 元／人；单项简历修改为 20 元／次，模拟面试为 50 元／次、约 45 分钟。半包赠送简历修改或模拟面试一次，二选一；全包每周可按需预约一次辅导。

同一轮次已付套餐费与单项费用可抵扣升级，累计收费上限为 500 元。例如，200 元基础指导、20 元简历修改和 50 元模拟面试合计 270 元，升级全包补付 230 元。当前本人确认的规则为付款后不予退款；后续调整时应同步核对正文中的全部收费说明。

具体服务范围、申请轮次与当期人数安排以正文为准。本人经历按已确认的公开资料填写，招生条件和考核安排以院校当年官方通知为准。

## 页面验证与数据

套餐表采用三列，正文容器内的表格允许文字换行，避免电脑与手机出现横向溢出。修改内容或排版后运行 `pnpm check`、`pnpm type-check` 和 `pnpm build`，并预览桌面与手机页面。

个人站不读取保研工作台或学生记录。学生、付款、运营草稿和调研记录继续保存在本机被 Git 忽略的目录中，构建结果和预览截图也不提交。网站当前仅完成本地实现，尚未部署。
